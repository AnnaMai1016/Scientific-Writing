# Writing Science 

A personal toolkit for improving scientific writing, built on the ideas in *Writing Science: How to Write Papers That Get Cited and Proposals That Get Funded* by Joshua Schimel (Oxford University Press, 2012).

> **All materials in this repository were handmade by me (Liting Mai).** I created the slides, the written guide, and the auditing skill myself, based on my own reading of Schimel's book. This is not an official companion to the book. It is not affiliated with or endorsed by the author or the publisher.

## What's Inside

| Item | Purpose |
|---|---|---|
| PowerPoint (`.pptx`) | A presentation on the book's core ideas, for sharing with my group |
| Word (`.docx`) | An OCAR-structured paper template, ready to download and fill in |
| `Scientific-Writing-Auditor/` Claude skill | A checklist-driven auditor for reviewing a paper after the first draft is done |

#### Suggested Workflow

1. Finish the complete first draft.
2. Ask Claude to audit the draft with `Scientific-Writing-Auditor`, one section at a time or for the whole paper.
3. Revise based on the diagnosis.
4. Run the audit again on the revised draft if needed.
